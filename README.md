# דף נחיתה B2B לשיתופי פעולה — שופ SHOP

דף נחיתה סטטי בעברית (RTL) שמטרתו אחת: לגרום לבעלי עסקים ומנהלי שיווק לפנות לסגירת
שיתוף פעולה במודל שותפים (Affiliate) עם רשת שופ.

- **טכנולוגיה:** HTML + CSS + JavaScript ונילה בלבד. בלי פריימוורקים, בלי build step, בלי תלויות.
- **קבצים:** `index.html` · `css/style.css` · `js/main.js` · `assets/logo.png` · `og-image.png` · `favicon.svg` · `robots.txt` · `sitemap.xml`

---

## פריסה ל-GitHub Pages (צעד אחר צעד)

1. נכנסים לריפו בגיטהאב → **Settings** → **Pages** (בתפריט הצד).
2. תחת **Build and deployment** → **Source** בוחרים **Deploy from a branch**.
3. בוחרים את הענף הראשי (`main`) ואת התיקייה `/ (root)` → **Save**.
4. ממתינים כדקה־שתיים. הכתובת תופיע למעלה: `https://<שם-משתמש>.github.io/<שם-ריפו>/`.
5. **חשוב:** לאחר שהכתובת ידועה — לעדכן אותה בכל המקומות המפורטים בטבלת הפלייסהולדרים למטה.

## פריסה ל-Vercel (צעד אחר צעד)

1. נכנסים ל-[vercel.com](https://vercel.com) ומתחברים עם חשבון GitHub.
2. **Add New… → Project** → בוחרים את הריפו הזה → **Import**.
3. ב-**Framework Preset** משאירים **Other**. אין Build Command ואין Output Directory (אתר סטטי מהשורש).
4. **Deploy**. תוך שניות מתקבלת כתובת `https://<project>.vercel.app` (אפשר לחבר דומיין משלכם ב-Settings → Domains).
5. **חשוב:** לעדכן את הכתובת בכל הפלייסהולדרים למטה.

## איך מחליפים צ'יפ מותג בלוגו־תמונה?

צ'יפי המותגים בפס האמון הם טקסטואליים בכוונה. כשיש קובץ לוגו רשמי של מותג:

1. לשמור את הקובץ בתיקייה `assets/brands/` (למשל `assets/brands/nike.svg`).
2. ב-`index.html`, למצוא את הצ'יפ ולהחליף את הטקסט בתמונה:

```html
<!-- לפני -->
<li class="chip">Nike</li>

<!-- אחרי -->
<li class="chip chip-logo"><img src="assets/brands/nike.svg" alt="Nike" height="22"></li>
```

3. להוסיף ל-`css/style.css` (פעם אחת):

```css
.chip-logo img { height: 22px; width: auto; display: block; }
```

הצ'יפים משוכפלים אוטומטית ב-JavaScript לצורך לולאת הגלילה — אין צורך לשכפל ידנית.

## הערות טכניות

- **ה-iframe של הטופס** נטען בעצלנות דרך IntersectionObserver (רק כשמתקרבים לסקשן), כדי לא לפגוע בביצועים.
- **תמונת ה-OG** (`og-image.png`, ‏1200×630) נוצרה מ-HTML שעוצב ותואם לשפה העיצובית של העמוד. כדי לחדש אותה אחרי החלפת הלוגו — אפשר לערוך אותה בכל כלי עיצוב, או לשחזר את התהליך: עמוד HTML בגודל 1200×630 וצילום מסך.
- **אנימציות** מכבדות `prefers-reduced-motion` — גולשים שביקשו הפחתת תנועה יקבלו עמוד סטטי לגמרי.
- **סושיאל:** בעמוד יש קישורים רק לשלוש הקהילות (קבוצת פייסבוק, ערוץ וואטסאפ, ערוץ טלגרם); טיקטוק, פינטרסט וגוגל ביזנס מוזכרים בטקסט בלבד — כך הוגדר במפרט.
